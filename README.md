# net-diagnostics-cli

Network diagnostics command-line tool written in C.

Current commands (stubbed):

- `ping <host>`  — planned ICMP echo (ping) implementation
- `trace <host>` — planned traceroute-style path discovery
- `scan <host>`  — planned TCP port scanner
- `dns <name>`   — planned DNS resolver

This initial version only provides the CLI skeleton and help text.
